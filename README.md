# MyDotWork · 研究、聊天原文与项目进度

基于公开页面证据的研究总库。包含渠道与多 SKU 检索、卡片/表格展示、价格排序、成本场景、证据原链及历史结论。

报价不是实时库存或成交承诺。页面制作时间、来源观察日期与内容版本分别记录；历史促销、未知费用、税票与授权缺口不得当作已验证现状。

## 本地构建

Python 3.12，无第三方依赖：

```sh
python scripts/build.py
python scripts/validate.py
python -m http.server 8000 --directory dist
```

GitHub Actions 在主分支变更时验证并部署 Pages。PR 仅构建验证。仅使用 GitHub 临时部署权限，不要求任何个人访问令牌。

## 维护

- `src/` 保存供货研究；`data/` 保存用户已明确授权公开、已脱敏的当前dot对话与项目状态
- 更新需保留观察日期、来源、证据状态；修改版本与 CHANGELOG
- 每次构建生成含 SHA-256 的 `release-manifest.json`
- 发布前运行验证并检查对应提交的 Actions 和实际网站版本
- 个人进化网站使用同一内容版本与公开报告副本，并记录上游提交和哈希；通过其原有私仓构建与发布流程更新
- 无定时商家接口抓取；研究记录经核验后提交才触发构建

## 公开边界

用户于2026-10-02明确批准：当前dot可见对话去除秘密后保留原文，私人关系、未公开项目及Git历史也可公开，并同步个人进化网站。此授权不扩展到其他Codex/GPT会话全文、附件本体、内部提示、工具报告或内部记忆原件。不得提交密码、Token、身份证号、银行卡号、签名URL或恢复凭据。证据区保留公开商家事实与公开原链。研究不会证明特定商家的资金来源、转售授权或未来履约能力。

## 聊天与项目归档

- `chat/index.html`：完整保留本次可取得的可见消息原文，提供搜索与角色筛选
- `chat/messages.json`：真实消息ID、角色、原始时间与脱敏文字
- `chat/coverage.json`：计数、起止、工具可见历史是否读取到末尾和已知缺口
- `projects/index.html` 与 `projects/status.json`：项目状态及未验收边界
- 仅把脱敏后的内容写入工作目录和Git；不得先提交原始秘密再删除
- 按消息ID去重，增量追加；无来源时不得编造消息、ID、时间或完整性
- `scripts/validate_archive.py` 逐条比较JSON与HTML文字，检查秘密、链接及产物哈希
- 扩大公开范围必须有新的用户授权；现有每日同步不包括外部会话全文和附件
