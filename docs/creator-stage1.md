# 六模块创作工作区：阶段 1 候选

入口是 `creator/index.html`。工作台、选题池、创作台、日历、作品库和数据库围绕同一个稳定作品 ID 工作。原研究工作台、53 条公开目录记录、567 条公开聊天、原项目与资料页面保留。

这是独立实现。参考视频的作者正文确认了六个模块和贯通创作的用途；完整视频画面与动效尚未核实，候选不声称复刻其界面或动效。

## 当前使用范围

- 默认只用于虚构演示。页面不预填用户的真实账号、稿件、发布时间或指标，也不连接模型和社媒服务
- 所有来源均默认关闭私有备份导入。没有通过网址参数、本地偏好或界面开关启用真实私稿的通道
- MyDotWork 与 Evolution 的 GitHub Pages 路径处于同一浏览器来源，路径和 IndexedDB 名称不能提供安全隔离
- 写作、录制、剪辑是作品内容与进度管理，不是内置录制或视频剪辑软件
- 排期只记录计划；发布必须由使用者手工登记。到期不会自动上传或发布
- 浏览器本地保存可能因清理、隐私模式或环境替换丢失，不是云端备份

## 一条作品的操作链

在选题池新建虚构标题、参考和原创切入点，开始创作。保存稿件版本，记录写稿、录制、剪辑等任务。必需任务未完成时，“可发布”检查会列出缺项；阻塞或不适用需要说明原因。

在日历为作品选择账号和时区，安排全天或具体时间。改期和取消计划保留稿件，取消后可重新安排。日期已过但没有发布事实的记录需要核实。手工登记真实发布事实的操作在演示中也必须只使用虚构数据；发布记录保留当时稿件版本。

指标从手工输入或预览后的指标 CSV 得到。空白表示未知，只有明确输入的 0 才是零。两次累计播放量 100、160，在第二个截止时刻的累计值是 160，同口径增量是 60。不同平台、指标和定义分别展示。复盘可以派生一条新选题，并保留原作品与证据关系。

## 保存、恢复和交换

共享核心只处理数据和业务规则；浏览器适配器负责 IndexedDB 事务。界面等待提交成功后才显示已保存。工作区版本不符时拒绝写入并保留输入，不能按设备时间静默覆盖。

JSON 备份协议包含已保存业务记录的稳定 ID、实体版本与哈希、关系、来源工作区以及附件清单。全量模式包含独立账号与目标；选择作品时会显示关联范围。它不复制浏览器配置、操作流水、撤销历史、现有恢复点或未保存输入。未保存输入可另行导出供人工取回，不能当作标准交换包导入。阶段 1 不携带附件本体，不会把文件名或网址称为已备份的视频。当前演示来源的导入按钮保持关闭；在真实浏览器中用纯合成数据测试适配器恢复，与向用户开放私稿导入是不同验收项。

删除采用可恢复回收站。导入需要先预览新增、相同、较旧、分叉冲突和缺失附件，实际提交与恢复点原子保存。冲突须明确选择，没有自动按最新时间覆盖。CSV 只追加指标，不能借字段修改作品正文、公开许可或发布状态。

## 构建与保留边界

`python3 scripts/build.py` 从明确源文件清单构建到全新临时目录，成功后替换已验证的 `dist`。若旧输出中出现未知文件、目录或符号链接，构建停止并保留原文件。创作运行时只复制十个明确的代码文件，不读取浏览器数据库、私人备份、CSV、附件或其他目录。

公开目录和公开创作应用代码是两种输入；私有创作记录不能写入 `data/workbench-catalog.json`、研究 JSON 或内嵌 HTML。示例加载需明确操作，所有示例均为虚构。代码不提供后台同步、平台自动抓数、自动发布或伪 AI 结果。

## 验收说明

业务和适配器单元测试、静态 DOM 契约、构建白名单检查，与真实浏览器验收分别记录。内存适配器或模拟 IndexedDB 通过不能证明真实浏览器持久化成功。实际截图、键盘、刷新重开、跨标签并发、全新浏览器恢复和 320–1280px 布局仍需在可访问的获准预览中验证。

本候选没有发布到 GitHub Pages 或同步 Evolution。旧站内容版本仍是基线版本，创作模块标记为阶段 1 候选。Obsidian 适配保留在共享接口之后，当前未安装插件或声称已完成原生宿主测试。
